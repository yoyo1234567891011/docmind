# Corpus `real-anonymized`

Documents **réels anonymisés** consommés par :

```bash
npm run evaluate -- --corpus real
npm run test:docs -- --corpus real
```

Ajout d’un document : voir `corpus/README.md` et `npm run corpus:import`.

Ne pas lancer `generate:docs` en espérant régénérer ce dossier — il est **préservé** volontairement.
